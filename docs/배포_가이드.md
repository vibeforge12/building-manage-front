# Building Manager 배포 가이드

> 작성일: 2026-04-21
> 버전: 1.0

---

## 1. 개요

프론트엔드 앱 배포는 **Fastlane**을 사용합니다. 로컬(Mac)에서 수동 실행하는 구조이며, CI/CD 서버는 사용하지 않습니다.

---

## 2. 사전 요구사항

### 2.1 환경

- macOS
- Homebrew Ruby 3.x 이상 (시스템 Ruby 2.6은 호환 불가)
- CocoaPods 1.16+ (Homebrew로 설치)
- Flutter 3.32+ (fvm 사용)
- Xcode 26.4+

### 2.2 설치 (최초 1회)

```bash
# Homebrew Ruby 설치
brew install ruby

# PATH 추가 (~/.zshrc에 영구 저장 권장)
export PATH="/opt/homebrew/opt/ruby/bin:$PATH"

# CocoaPods 설치
brew install cocoapods

# 프로젝트 의존성 설치
cd "/path/to/building-manage-front"
bundle config set --local path 'vendor/bundle'
bundle install
```

## 3. iOS 배포 (TestFlight)

### 3.1 인증 파일

**App Store Connect API Key** (.p8) 필요:
- 위치: 프로젝트 루트 상위의 `../private_keys/AuthKey_{KEY_ID}.p8`
- 파일 이름 형식: `AuthKey_{KEY_ID}.p8`
- 절대 git에 커밋 금지

**Key 정보**: 관리자에게 별도 문의
- Key ID
- Issuer ID
- Team ID

### 3.2 빌드+업로드 명령어

```bash
cd "/path/to/building-manage-front/ios"
export PATH="/opt/homebrew/opt/ruby/bin:$PATH"

# 빌드 번호 올리기 (pubspec.yaml +1)
bundle exec fastlane ios bump_build

# IPA 빌드만 (업로드 안 함)
bundle exec fastlane ios build

# 기존 IPA만 TestFlight 업로드
bundle exec fastlane ios upload

# 빌드 + 업로드 (한 번에)
bundle exec fastlane ios beta
```

### 3.3 버전 관리

`pubspec.yaml`의 `version: X.Y.Z+B` 형식:
- `X.Y.Z`: 버전 이름 (예: 1.0.7)
- `B`: 빌드 번호 (매 업로드마다 +1 필수, TestFlight에서 중복 불가)

### 3.4 배포 흐름

1. 코드 수정/커밋
2. `fastlane ios bump_build` 또는 수동으로 `pubspec.yaml` 빌드 번호 +1
3. `fastlane ios beta` 실행
4. App Store Connect / TestFlight에서 처리 완료 확인 (약 5분)
5. TestFlight 앱에서 테스터가 설치 가능

## 4. Android 배포 (Play Store)

**현재 미구현 상태** (keystore 파일 필요).

### 4.1 필요한 것

1. `building_manage.jks` keystore 파일 (기존 개발자로부터 수령)
2. Google Play Console API JSON Key
3. Android Fastfile 작성

### 4.2 구현 예정

Android fastlane 설정은 keystore 수령 후 진행 예정.

## 5. 파일 구조

```
building-manage-front/
├── Gemfile                              # fastlane 의존성
├── ios/
│   ├── fastlane/
│   │   ├── Fastfile                    # lane 정의
│   │   └── Appfile                     # 앱 식별자, 팀 ID
│   └── ExportOptions.plist             # IPA export 설정

# 프로젝트 루트 상위 (민감 정보, git 제외)
../
└── private_keys/
    └── AuthKey_{KEY_ID}.p8              # App Store Connect API Key
```

## 6. 트러블슈팅

### 6.1 "CocoaPods is installed but broken"
- 원인: CocoaPods가 다른 Ruby로 설치됨
- 해결: `brew install cocoapods`

### 6.2 "Could not retrieve response as fastlane runs in non-interactive mode"
- 원인: fastlane 명령어를 프로젝트 루트에서 실행
- 해결: `cd ios && bundle exec fastlane ios beta`

### 6.3 "Unable to flip between RX and RW memory protection"
- 원인: iOS 18.4+ debug 모드 JIT 제한
- 해결: Release 모드 사용 (`flutter run --release`), 개발자 모드 활성화

### 6.4 빌드 번호 중복 에러
- 원인: 같은 빌드 번호 재업로드 시도
- 해결: `fastlane ios bump_build` 또는 `pubspec.yaml`에서 빌드 번호 증가
